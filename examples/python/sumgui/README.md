# sumGUI examples in sumIDE

These are Python examples for the shared Sum graphical backend.  They live in the common IDE example tree so Python graphical programs are discoverable beside the other language examples instead of being treated as a separate language.

Run them with an installed `sumGUI`/Pygame environment, for example:

```bash
python demo_full.py
python components/demo_all.py
```

The source copies intentionally remain plain Python.  `sumGUI` is the graphical UI backend; it is not a language frontend.
